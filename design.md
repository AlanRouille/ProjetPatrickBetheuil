# Patrick Bétheuil — Design System

> Source de vérité visuelle du projet Patrick Bétheuil.
>
> Le Figma est la référence absolue.
>
> L'objectif est de créer une expérience artistique contemporaine où les œuvres sont toujours au centre de l'attention.

## Identité

- Marque : Patrick Bétheuil
- Baseline : Invitation à mon imaginaire
- Positionnement : galerie numérique contemporaine, catalogue d'exposition vivant

## Couleurs

```css
--pb-black: #0F0F0E;
--pb-white: #FFFFFF;
--pb-accent: #F49C1A;
--pb-muted: #9D9D9D;
--pb-border: rgba(255,255,255,.08);
```

## Layout

- Largeur max : 1440px
- Padding desktop : 80px
- Padding mobile : 24px
- Espacement sections desktop : 120px
- Espacement sections mobile : 80px

## Navigation

- Accueil
- À propos
- Galerie
- Contact

## Hero

- Œuvre principale
- Titre éditorial
- Sous-titre
- CTA principal
- CTA secondaire

Aucun slider.
Aucune vidéo automatique.

## Animations

GSAP uniquement.

Autorisé :
- Fade Reveal
- Text Reveal
- Image Reveal
- Page Transition
- Hover subtil

Interdit :
- Bounce
- Scroll Hijacking
- Locomotive Scroll
- Zoom excessif

## Règles Absolues

1. Le Figma est la source de vérité.
2. Les œuvres sont toujours prioritaires.
3. Une seule couleur d'accent : #F49C1A.
4. Montserrat pour toute l'interface.
5. Aucun style SaaS.
6. Aucun emoji.
7. Aucun carrousel automatique.
8. Aucune animation agressive.
9. L'interface doit toujours s'effacer au profit des œuvres.
